# AI Lead Follow-Up Assistant — Prototype Build Kit

This package is designed to be uploaded to an AI coding tool as a complete prototype handoff.

## Recommended upload order
1. PRD
2. Technical Design
3. Prompt & Behavior Spec
4. User Stories / Acceptance Criteria
5. Test Plan
6. Build & Deployment Guide
7. Sample Data Workbook
8. Master Build Prompt

## Recommended first instruction
Open `08_Master_Prompt_for_AI_Coding_Tools.md` and follow it. Build Sprint 1 only, run tests, and report results before continuing.

## Product boundary
The MVP is human-in-the-loop and draft-only. It does not autonomously send messages or make customer commitments.
